# Руководство по контенту

**Статус:** Действует
**Владелец:** Системный аналитик
**Обновлено:** 2026-11-13

Как добавлять и править кейсы, дорожные карты, статьи, менторов и волонтёрские задачи, и какие правила проверяют тесты. Причины решений — в [ADR-0003](../architecture/adr/0003-content-as-code.md) и [ADR-0006](../architecture/adr/0006-roadmap-diagram-json.md).

## Где что лежит

| Контент | Файл | Формат |
|---------|------|--------|
| Roadmap | `content/roadmaps/<slug>.md` | Markdown |
| Схема roadmap | `content/roadmaps/<slug>.diagram.json` | JSON |
| Статья блога | `content/blog/<slug>.md` | Markdown |
| Кейс | `internal/cases/<имя>.go` | Go-код |
| Направления, менторы, волонтёрские задачи | `internal/catalog/catalog.go` | Go-код |

## Roadmap

Файл `<slug>.md`: заголовок первого уровня (название), затем вводный абзац (он же краткое описание в каталоге), затем разделы второго уровня. Раздел «Критерии прогресса» (список) на странице превращается в чек-лист с отметками, которые хранятся в браузере. Первый `##` делит страницу на введение и основную часть; схема вставляется между ними.

Slug совпадает с `RoadmapSlug` направления в каталоге. Чтобы направление показывало кнопку кейса, задайте `CaseSlug`.

## Схема roadmap

Файл `<slug>.diagram.json`:

```json
{
  "stages": [
    {
      "title": "HTML",
      "note": "Разметка — основа любой страницы.",
      "choose": false,
      "nodes": [
        {
          "id": "html-semantic",
          "title": "Семантические теги",
          "kind": "core",
          "summary": "Краткое описание темы для боковой панели.",
          "links": [{ "title": "MDN: HTML", "url": "https://developer.mozilla.org/ru/docs/Web/HTML" }]
        },
        { "id": "mentors", "title": "Консультация наставника", "kind": "core", "href": "/mentors" }
      ]
    }
  ]
}
```

| Поле | Правило |
|------|---------|
| `id` | Обязателен, уникален в схеме, латиница в нижнем регистре, цифры и дефисы. Это адрес темы `#t-<id>`, не меняйте его без нужды |
| `kind` | `core` (основа), `also` (на выбор), `optional` (по желанию); по умолчанию `core` |
| `choose` | `true`, если достаточно выбрать один узел этапа; тогда все узлы этапа `also` |
| `summary` | До 400 символов, 1–2 предложения: что это и зачем |
| `links` | До 5 внешних ссылок, только `https://`; у каждой есть `title` |
| `href` | Внутренний путь или `https://`. Нельзя вместе с `summary`: такой узел просто ведёт по ссылке |

Требования к полноте: у каждой темы есть описание или внутренняя ссылка; не менее 65% тем имеют внешние материалы. Файл читается строго: лишние поля, пустые названия и неизвестный `kind` считаются ошибкой, страница вернёт 500 `Что-то пошло не так`, а тест `internal/content` укажет причину.

После правки ссылок выполните `make check-links`: ответы 403 и 429 считаются предупреждением, остальные ошибки — отказом.

Структуру чужих roadmap (в том числе roadmap.sh) копировать нельзя: схемы составляются самостоятельно, ссылки на внешние ресурсы допустимы.

## Статья блога

Файл `<slug>.md`: заголовок первого уровня, строка `Дата: ГГГГ-ММ-ДД` (если нужна дата публикации), затем текст. Первый абзац используется как краткое описание в списке. Markdown санитизируется (bluemonday): скрипты и небезопасные атрибуты удаляются.

## Кейс

Кейс — Go-структура `domain.CareerCase` в `internal/cases`. Правила, которые проверяют тесты:

- Идентификаторы вопросов и вариантов уникальны в кейсе.
- В каждом вопросе не меньше 3 вариантов и ровно один верный.
- У каждого варианта есть пояснение, у каждого вопроса — тема (по темам считается разбивка результата).
- `RoadmapSlug` указывает на существующий roadmap.
- Кейс добавляется в `cases.All()`, для него создаётся направление или задаётся `CaseSlug` существующего.
- Формулировки без оценки человека: результат — ознакомительный, не диагноз профессии.

## Менторы и волонтёрские задачи

Записи лежат в `internal/catalog/catalog.go` и загружаются при старте. Slug в нижнем регистре с дефисами (`daria-backend`), он становится частью адреса `/mentors/<slug>`. Заявки привязываются к slug, поэтому менять его у существующей записи нельзя.

## Что проверяют тесты

| Тест | Проверяет |
|------|-----------|
| `TestRealRoadmapDiagrams` | Каждая схема валидна, не короче 6 этапов, введение и разделы разделены верно |
| `TestDiagramValidation` | Ошибки формата отклоняются (17 случаев) |
| `TestRealDiagramNodesAreComplete` | У каждой темы есть описание или ссылка, не менее 65% тем с материалами |
| `TestRoadmapDiagramRendered`, `TestRoadmapTopicPanel` | Схема и панель тем отображаются |
| `TestAllPagesRender` | Все страницы контента открываются |
