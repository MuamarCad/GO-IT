# Глоссарий

**Статус:** Действует
**Владелец:** Системный аналитик
**Обновлено:** 2026-11-13

Термины проекта в алфавитном порядке. Новый термин добавляется в том же изменении, которое его вводит.

| Термин | Определение |
|--------|-------------|
| ADR | Architecture Decision Record: запись принятого технического решения с контекстом, альтернативами и последствиями. См. [индекс](../architecture/adr/README.md) |
| CSRF | Подделка межсайтового запроса. Защита: одноразовый токен в форме, который проверяется на сервере. Применяется в формах кейсов и заявок |
| Definition of Done | Критерии готовности изменения: форматирование, `go vet`, тесты, открытые страницы, обновлённые документы |
| HTMX | Небольшая библиотека, подменяющая части страницы ответом сервера. Используется для шагов кейса |
| PRG | Post/Redirect/Get: после POST сервер отвечает редиректом, а не страницей, чтобы обновление страницы не повторяло действие |
| RFC | Request for Comments: предложение, которое обсуждается до реализации. См. [каталог RFC](../rfc/0001-rest-api/README.md) |
| SSR | Серверный рендеринг: HTML собирает сервер ([ADR-0001](../architecture/adr/0001-server-side-rendering.md)) |
| Seed-данные | Начальные менторы и волонтёрские задачи из `internal/catalog`, загружаются при старте |
| Демо-вход | Вход без проверок, cookie и сессий: выбранная роль превращается в переход в кабинет ([ADR-0005](../architecture/adr/0005-demo-auth-without-state.md)) |
| Кабинет (ЛК) | Личный кабинет ученика, ментора или партнёра. Показывает условные данные, открывается по адресу `/lk/<роль>` |
| Кейс | Интерактивный сценарий с вопросами; ответы и баллы считает сервер |
| Попытка | Состояние прохождения кейса, хранится в сессии |
| Роль | `student`, `mentor` или `partner`: определяет, в какой кабинет ведёт вход |
| Roadmap | Дорожная карта обучения: Markdown с разделами и схема этапов в JSON |
| Сессия | Серверное состояние пользователя (ход кейса, CSRF-токен) с подписанным cookie. Нужна только кейсам и формам заявок ([ADR-0004](../architecture/adr/0004-sessions-in-memory.md)) |
| Тема (узел) | Элемент схемы roadmap; открывает боковую панель с описанием и материалами |
| Тема оформления | Светлая, тёмная или контрастная палитра ([дизайн-система](../design/design-system.md)) |
| Токен (дизайн) | CSS-переменная с цветом, радиусом или тенью |
| Токен (CSRF) | Случайная строка в скрытом поле формы, подтверждающая, что запрос отправила наша страница |
