# ADR-0006: Схема roadmap как JSON со строгой валидацией и панелью на dialog

**Статус:** Принят
**Владелец:** Tech Lead
**Обновлено:** 2026-11-13
**Дата решения:** 2026-11-09

## Контекст

Нужна визуальная схема маршрута обучения с возможностью «проваливаться» в материалы по теме. Структуру сайта roadmap.sh копировать нельзя: лицензия репозитория, как мы её прочитали, разрешает только личное использование и запрещает публиковать содержимое схем без согласия автора, поэтому схемы составлены самостоятельно (актуальные условия лицензии стоит перепроверить).

## Решение

Схема описывается в `content/roadmaps/<slug>.diagram.json` (этапы и темы: `id`, `title`, `kind`, `summary`, `links` или `href`) и рисуется обычным HTML и CSS. Файл проверяется строго при загрузке (уникальные `id`, только `https`-ссылки, лимиты). Тема открывается в боковой панели на `<dialog>`; без JS темы ведут к справочнику под схемой.

## Рассмотренные альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---------|-------|--------|------------------|
| Картинка или SVG | Простота | Не масштабируется, нет доступности, не меняется темой | Нужны темы, клавиатура, ссылки |
| Библиотека диаграмм | Готовые возможности | Зависимость, вес, доступность | HTML и CSS достаточно |

## Последствия

Плюсы: схема доступна, работает со всеми темами, ссылки и описания меняются в тексте. Минусы: описания и материалы нужно писать для каждой темы; адреса внешних ссылок могут устареть (проверка `make check-links` вручную). Формат — в [руководстве по контенту](../../engineering/content-guide.md#схема-roadmap).
