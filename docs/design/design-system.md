# Дизайн-система

**Статус:** Действует
**Владелец:** Продуктовый дизайнер
**Обновлено:** 2026-11-13

Описывает визуальные токены, темы и компоненты интерфейса GO-IT и правила доступности. Источник правды — `static/css/app.css`; документ объясняет, как им пользоваться. Исходные макеты лежат в `draft/`, фирменные правила — в [бренд-буке](brand-book.docx). Решение по токенам и темам — [ADR-0008](../architecture/adr/0008-css-tokens-and-themes.md).

## Принципы

1. **Токены, а не значения.** Цвета, радиусы и тени берутся из CSS-переменных на `:root`. Прямые шестнадцатеричные цвета в компонентах допустимы только внутри самих тем.
2. **Три темы равноправны.** Новый компонент проверяется в светлой, тёмной и контрастной темах.
3. **Доступность не опция.** Контраст, фокус, управление с клавиатуры и работа без JS — часть определения готовности.
4. **Цвет не единственный носитель смысла.** Вид узла схемы, статус заявки и ошибка поля дополнены текстом, рамкой или значком.

## Токены

Основные переменные светлой темы (полный список — в начале `app.css`):

| Токен | Значение | Назначение |
|-------|----------|-----------|
| `--bg` / `--bg-alt` / `--surface` | `#ffffff` / `#f4f8ff` / `#ffffff` | Фон страницы, чередующийся фон секций, фон карточек |
| `--text` / `--muted` | `#101418` / `#4b5563` | Основной и вторичный текст |
| `--primary` / `--primary-ink` | `#1d4ed8` / `#ffffff` | Основной цвет действия и текст на нём |
| `--accent-bg` | `#eaf3ff` | Фон выбранных и выделенных элементов |
| `--border` | `#d7e3f5` | Декоративные границы карточек |
| `--border-strong` | `#6b7a90` | Границы полей, вариантов ответа, кнопок (элементы управления) |
| `--focus` | `#1d4ed8` | Кольцо фокуса |
| `--ok`, `--error` и их `-bg` | `#0f7b3e`, `#b42318` | Успех и ошибка |
| `--hero-bg`, `--hero-text`, `--hero-muted` | `#0a1240`, `#ffffff`, `#c9d6f2` | Тёмные секции |
| `--cyan` | `#22e3f2` | Акцент на тёмном |
| `--cta-bg`, `--cta-ink` | `#ff7a1a`, `#101418` | Главная кнопка |
| `--radius`, `--radius-sm` | `20px`, `12px` | Скругления |

Шрифты: заголовки — Unbounded (500 и 700), текст — Onest (переменный). Оба лежат в `static/fonts/` и подключаются через `@font-face`; запасные шрифты — системные.

## Темы

| Тема | Как включается | Особенности |
|------|----------------|-------------|
| Светлая | По умолчанию | Белый фон, фирменный синий |
| Тёмная | `data-theme="dark"` на `<html>` или системная настройка `prefers-color-scheme`, пока пользователь не выбрал тему | Тёмный фон `#070b18`, светлый текст `#f3f6fc` |
| Высокая контрастность | `data-contrast="high"` (комбинируется с любой темой) | Чёрные границы, подчёркнутые ссылки, чёрно-белая палитра с жёлтой кнопкой |

Выбор хранится в `localStorage` (`goit-theme`, `goit-contrast`). Скрипт `static/js/theme-init.js` стоит в `<head>` и применяет тему до отрисовки, поэтому вспышки нет. Кнопки переключения имеют `aria-pressed` и подпись, меняющуюся с состоянием.

## Доступность

| Правило | Как соблюдается |
|---------|-----------------|
| Контраст текста не ниже 4,5:1 | Все пары «текст на фоне» в трёх темах рассчитаны при разработке; например, `--muted` на `--bg` в светлой теме: 7,56:1 |
| Контраст границ элементов управления не ниже 3:1 | `--border-strong` на `--bg`: 4,36:1 (светлая), 6,11:1 (тёмная), 21:1 (контрастная) |
| Фокус виден | Кольцо `outline: 3px solid var(--focus)` на всех интерактивных элементах |
| Цель нажатия не меньше 44 px | Кнопки-иконки 44×44, основные кнопки высотой не менее 48 px |
| Работа без JS | Меню, тема, шаги кейса, панель темы roadmap имеют запасное поведение |
| Движение | Анимации отключаются при `prefers-reduced-motion: reduce` |
| Формы | У каждого поля `label`, ошибка связана через `aria-describedby`, поле помечено `aria-invalid` |
| Структура | Ссылка «К содержанию», один `h1` на страницу, навигация подписана |

При изменении палитры контраст пересчитывается заново: токены нельзя менять «на глаз».

## Раскладка

Контейнер `.wrap` шириной до 1200 px. Брейкпоинты: 980 px (сетки из трёх колонок переходят в две), 860 px (одна колонка, бургер-меню) и 600 px (всё в одну колонку). Подход: сначала горизонтально гибкая раскладка на `flex`/`grid`, затем уточнение медиазапросами.

## Компоненты

| Компонент | Классы | Правила |
|-----------|--------|---------|
| Кнопки | `.btn`, `.btn--cta`, `.btn--primary`, `.btn--outline`, `.btn--ghost`, `.btn--sm` | Одна `cta` на экран; `ghost` только на тёмном фоне |
| Карточка | `.card` | Тень и скругление из токенов; заголовок `h2` или `h3` по контексту |
| Тег | `.tag` | Короткая метка; не заменяет заголовок |
| Сообщение | `.alert--ok`, `.alert--error` | `role="status"` или `role="alert"`; цвет дополнен текстом |
| Поле формы | `.field`, `.field-error` | Подпись над полем, ошибка под ним |
| Схема roadmap | `.rm`, `.rm-stage`, `.rm-node--core/also/optional`, `.rm-panel` | Вид узла передаётся рамкой (сплошная, тонкая, пунктирная), легендой и скрытой подписью |
| Кабинет | `.lk-layout`, `.lk-sidebar`, `.lk-nav`, `.lk-item`, `.lk-badge` | Единый сайдбар `partials/lk_sidebar.html`, иконки контурные (`.lk-nav-icon`) |
| Вход | `.auth-role-tab` | Роли — настоящие радиокнопки |

Иконки кабинета контурные: заливка и обводка заданы правилом `.lk-nav-icon`, чтобы атрибуты в разметке не ломали вид (причина дефекта из [аудита 2026-11-11](../quality/audits/2026-11-11-audit.md)).

## Как добавить компонент

1. Используйте токены; новые значения добавьте как токены во все три темы.
2. Проверьте контраст и фокус в трёх темах и на ширинах 390 и 1280 px.
3. Проверьте управление с клавиатуры и работу без JS.
4. Опишите компонент в таблице выше.
