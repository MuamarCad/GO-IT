# Индекс записей решений (ADR)

**Статус:** Действует
**Владелец:** Tech Lead
**Обновлено:** 2026-11-13

ADR (Architecture Decision Record) фиксирует принятое техническое решение: контекст, выбор, альтернативы, последствия. Когда писать ADR и как, описано в [стандарте документации](../../standards/documentation-standard.md#9-записи-решений-когда-adr-когда-rfc). Шаблон: [adr.md](../../templates/adr.md). Принятый ADR не переписывается: при смене решения создаётся новый ADR, а старый получает статус `Заменён`.

ADR 0001–0004, 0007 и 0008 оформлены ретроспективно 2026-11-13 по состоянию кода; в поле «Дата решения» стоит дата ближайшего подтверждающего коммита, альтернативы восстановлены по контексту проекта.
