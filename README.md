# GO-IT: социальный код

**Статус:** Действует
**Владелец:** Команда
**Обновлено:** 2026-11-13

Студенческий MVP образовательной платформы: знакомство с IT-профессиями через кейсы, дорожные карты и демонстрационные каталоги взаимопомощи. Публичный деплой не предусмотрен, сайт запускается локально.

> Вся документация: [docs/README.md](docs/README.md) · Как вносить изменения: [CONTRIBUTING.md](CONTRIBUTING.md) · Безопасность: [SECURITY.md](SECURITY.md) · История: [CHANGELOG.md](CHANGELOG.md)

## Что внутри

- Главная и разделы: направления, кейсы, менторы, волонтёрство, roadmaps, блог, о проекте.
- Четыре кейса, ответы проверяет сервер: Frontend (20 вопросов), Backend (18), Project Manager (20), Product Manager (18). Результат с разбивкой по темам.
- Четыре roadmap со схемой и боковой панелью тем: Frontend, Backend, Project Manager, Product Manager.
- Каталоги менторов и волонтёрских задач, заявки сохраняются в PostgreSQL.
- Демонстрационный вход и три личных кабинета: ученик, ментор, партнёр.
- Темы: светлая, тёмная, высокая контрастность.

Стек: Go 1.22+, `html/template`, chi, HTMX, PostgreSQL, Docker Compose.

## Важно про вход и кабинеты

Вход только визуальный: проверок, паролей, cookie и сессий нет. Выберите роль и нажмите «Войти» (поля можно не заполнять), откроется кабинет роли. Данные в кабинетах условные. Не размещайте проект в открытой сети в таком виде ([почему](docs/architecture/adr/0005-demo-auth-without-state.md), [ограничения](SECURITY.md)).

## Быстрый старт

```bash
cp .env.example .env
docker compose up --build        # сайт и PostgreSQL
```

Откройте [http://localhost:8080](http://localhost:8080). Без Docker: `make test` и `make run` (заявки хранятся в памяти процесса). Подробности — в [руководстве разработчика](docs/engineering/development.md).

## Сценарий демонстрации (5–7 минут)

1. Проблема: сложно выбрать IT-направление и понять повседневные задачи.
2. Главная: структура платформы и карточка шага кейса.
3. Кейс Frontend: сервер считает балл, дисклеймер «не диагноз профессии».
4. Roadmap Frontend: схема, боковая панель темы со ссылками на материалы.
5. Профиль ментора или задача волонтёра: заявка, подтверждение `?sent=1`.
6. Вход как ментор и партнёр: принять и отклонить заявку, статус отображается.
7. Тема и контраст, фокус с клавиатуры, архитектура handler → service → repository.

## Проверки перед защитой

- [ ] `docker compose up --build` поднимает сайт и БД
- [ ] `go test ./...` проходит

- [ ] Все страницы трёх кабинетов открываются
