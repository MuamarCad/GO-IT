# GO-IT: социальный код

**Версия:** 2.0
**Дата:** 11 ноября 2026
**Статус:** Действующий

Студенческий MVP образовательной платформы: знакомство с IT-профессиями через кейсы, дорожные карты и демонстрационные каталоги взаимопомощи. Публичный деплой не предусмотрен, сайт запускается локально.

> Подробнее: [Спецификация](SPECIFICATION.md) · [План развития](PLAN.md) · [Контекст для AI](GIGACODE.md) · [Стандарт документации](DOC-STYLE.md)

## Что внутри

- Главная и вкладки по макету: направления, кейсы, менторы, волонтёрство, roadmaps, блог, о проекте.
- Четыре кейса, ответы проверяет сервер на Go: Frontend (20 вопросов), Backend (18), Project Manager (20), Product Manager (18). Результат содержит разбивку по темам, пояснения и ссылку на roadmap.
- Четыре roadmap со схемой и боковой панелью тем: Frontend, Backend, Project Manager, Product Manager.
- Каталоги менторов и волонтёрских задач (seed), заявки сохраняются в PostgreSQL.
- Демонстрационный вход (`/auth`) и три личных кабинета: ученик, ментор, партнёр.
- Темы: светлая, тёмная, высокая контрастность.

Стек: Go 1.22+, `html/template`, chi, HTMX (шаги кейса без перезагрузки, без JS работает как обычная форма), PostgreSQL, Docker Compose.

## Важно про вход и кабинеты

Вход демонстрационный: учётных записей и паролей нет, любой вход (в том числе с пустыми полями) открывает кабинет выбранной роли. Данные в кабинетах условные. Исключения: каталог менторов, последний пройденный в этой сессии кейс и профиль из «Настроек» (хранится только в сессии). Решения по заявкам тоже живут только в сессии. Не размещайте проект в открытой сети в таком виде.

## Запуск через Docker Compose

```bash
cp .env.example .env
docker compose up --build
```

Откройте [http://localhost:8080](http://localhost:8080). Приложение ждёт готовности Postgres, применяет миграции и наполняет seed-каталоги.

## Запуск без Docker

Нужны Go 1.22+ и (опционально) PostgreSQL. Без `DATABASE_URL` заявки хранятся в памяти процесса: удобно для вёрстки, для защиты используйте Compose.

```bash
make test
make run
```

## Сценарий демонстрации (5–7 минут)

1. Проблема: сложно выбрать IT-направление и понять повседневные задачи.
2. Главная: структура платформы и карточка шага кейса.
3. Кейс Frontend: сервер считает балл, дисклеймер «не диагноз профессии».
4. Roadmap Frontend: схема, боковая панель темы со ссылками на материалы.
5. Профиль ментора или волонтёрская задача: отправка заявки, подтверждение `?sent=1`.
6. Вход как ментор и партнёр: принять и отклонить заявку, статус сохраняется.
7. Тема и контраст, фокус с клавиатуры, архитектура handler → service → repository.
