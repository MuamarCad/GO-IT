# IT Product Manager

Product Manager — это человек, который определяет, ЧТО нужно пользователям и бизнесу, и обеспечивает delivery этого продукта.

## Что делает Product Manager

- Определяет видение продукта (product vision)
- Проводит user research и interviews
- Пишет user stories и acceptance criteria
- Приоритизирует бэклог
- Анализирует метрики
- Работает с командой разработки

## Ключевые навыки

- Product thinking
- Data analysis
- Communication
- Prioritization frameworks
- Agile methodology

## Цель направления

Научиться формулировать гипотезы, проверять их с пользователями и принимать решения на основе данных. После маршрута вы отличите «хочу фичу» от «нужна метрика».

## Базовые знания

- Разница между Product Manager и Project Manager.
- Как работают метрики: DAU, MAU, retention, churn.
- Что такое воронка конверсии и cohort analysis.
- Когда использовать A/B тест, а когда — интервью.

## Порядок тем

1. Product discovery: как понять, что строить.
2. User research: интервью, персоны, user stories.
3. Приоритизация: RICE, MoSCoW, WSJF.
4. Метрики и эксперименты: как измерить успех.
5. Roadmap: как коммуницировать стратегию.

## Практические мини-проекты

- Составить user story map для GO-IT.
- Провести 3 интервью с потенциальными пользователями.
- Написать hypothesis canvas для новой фичи.

## Критерии прогресса

- Вы можете обосновать решение данными, а не мнением.
- Каждая фича в бэклоге имеет acceptance criteria.
- Roadmap говорит «почему», а не только «что».
