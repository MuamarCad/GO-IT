**Версия:** 2.2
**Дата:** 12 ноября 2026
**Статус:** Действующий

> Связанные документы: [README](README.md) · [План развития](PLAN.md) · [Контекст для AI](GIGACODE.md) · [Стандарт документации](DOC-STYLE.md) · [Технический аудит](AUDIT-REPORT.md)

Статусы в этом документе подтверждены кодом и тестами на дату версии. Правило: статус «✅» ставится только вместе с тестом, который открывает функцию так, как её открывает пользователь (см. [DOC-STYLE §6](DOC-STYLE.md)).

## 1. Назначение

GO-IT — адаптивная веб-платформа для знакомства с IT-профессиями через интерактивные кейсы, дорожные карты и механизмы взаимопомощи (менторство, цифровое волонтёрство). Это студенческий MVP для защиты проекта, публичный деплой не предусмотрен.

Спецификация служит основой для оценки соответствия реализации требованиям, планирования и онбординга новых участников.

## 2. Область применения

### 2.1 Целевые аудитории

| Роль | Потребность | Используемые функции |
|------|-------------|---------------------|
| Школьник | Понять, какие IT-профессии существуют | Кейсы, направления, roadmaps |
| Студент младших курсов | Выбрать специализацию | Roadmaps, блог, ЛК ученика |
| Студент-наставник | Помочь начинающим | Профиль, ЛК ментора |
| Студент-волонтёр | Применить навыки для социальной задачи | Каталог задач, форма отклика |
| Социальный партнёр | Размещать волонтёрские задачи | ЛК партнёра |

### 2.2 Основные сценарии

- **Кейс** — выбрать направление, ответить на вопросы, получить результат с пояснениями и ссылкой на roadmap.
- **Roadmap** — изучить схему маршрута, открыть боковую панель темы со ссылками на материалы.
- **Заявка** — отправить заявку ментору или отклик на волонтёрскую задачу.
- **Демонстрационный вход** — открыть кабинет роли и пройти по его разделам.

## 3. Сценарии

### 3.1 Пройти кейс

1. `/cases` → выбор кейса (`/cases/{slug}`). Если попытка уже идёт, показывается текущий шаг.
2. Ответ отправляется `POST /cases/{slug}/answer` с CSRF-токеном. Сервер проверяет вариант, шаг и повторную отправку.
3. После последнего ответа открывается `/cases/{slug}/result`: баллы, разбивка по темам, пояснения, дисклеймер, ссылка на roadmap, кнопка «Пройти заново».
4. С включённым JS шаги меняются через HTMX без перезагрузки; без JS работает обычная форма (PRG).

### 3.2 Оставить заявку

Профиль ментора или карточка задачи → форма (имя, контакт, сообщение) → `POST` с CSRF → при успехе redirect с `?sent=1`, при ошибке ответ 422 с сообщениями у полей и сохранёнными значениями.

### 3.3 Изучить roadmap

`/roadmaps/{slug}` → введение → схема этапов → клик по теме открывает панель справа (описание и до 5 внешних ссылок); адрес темы `#t-<id>`. Без JS темы ведут к «Справочнику тем» под схемой. Ниже — разделы, оглавление и чек-лист «Критерии прогресса» (отметки в `localStorage`).

### 3.4 Демонстрационный вход и кабинеты

1. `/auth`: выбрать роль (ученик, ментор, партнёр) и нажать «Войти», либо «Войти через VK / Yandex ID», либо «Войти как Ментор / Партнёр». Поля можно не заполнять и заполнять любыми значениями: проверок нет.
2. Сервер сразу ведёт на `/lk/<роль>`. Cookie, сессия и токены не создаются.
3. Кабинеты открываются и по прямому адресу: входа как состояния нет. Данные в них условные.
4. В кабинете ментора и партнёра заявки можно принять или отклонить; решение отражается статусом и хранится в адресе страницы (`?h=…`).
5. «Выйти» — обычная ссылка на главную.

Реальной аутентификации нет сознательно (REQ-002 п.1 и решение заказчика от 12.11.2026): вход нужен только для демонстрации. Сессии в проекте остались у кейсов и форм заявок.

## 7. Архитектура

Слои: HTTP (chi, middleware: RequestID, RealIP, Recoverer, LimitBody, RequestLogger) → handlers → services (`CaseService`, `ApplicationService`) → repository (`memory`, `postgres`). Отдельно: `session.Manager` (серверная память, подписанный cookie), `content.Loader` (goldmark + bluemonday), `render.Renderer` (набор шаблонов на каждую страницу).

Пакеты, файлы и схема зависимостей — в [GIGACODE.md](GIGACODE.md#архитектура).

## 8. Маршруты

Всего 43 (включая обработчик 404). Правила: страницы входа и кабинетов не используют cookie, сессии и CSRF-токены; формы заявок и кейсы используют сессию и CSRF, их POST завершается redirect (PRG) либо ответом 422 с ошибками; неверный CSRF-токен — 403 с оформленной страницей. Страница 404 сессию не создаёт.

## 9. Требования к контенту

### 9.1 Формат схемы roadmap (`<slug>.diagram.json`)

```json
{
  "stages": [
    {
      "title": "HTML",
      "note": "Разметка — основа любой страницы.",
      "choose": false,
      "nodes": [
        {
          "id": "html-semantic",
          "title": "Семантические теги",
          "kind": "core",
          "summary": "Краткое описание темы для боковой панели.",
          "links": [{ "title": "MDN: HTML", "url": "https://developer.mozilla.org/ru/docs/Web/HTML" }]
        },
        { "id": "mentors", "title": "Консультация наставника", "kind": "core", "href": "/mentors" }
      ]
    }
  ]
}
```

Правила (проверяются при загрузке и в `loader_test.go`):
- `id` обязателен, уникален в схеме, латиница в нижнем регистре, цифры и дефисы.
- `kind`: `core`, `also` или `optional`; по умолчанию `core`.
- Либо `href` (внутренний путь или `https://`), либо `summary` (до 400 символов) и `links` (до 5 адресов только `https://`); вместе нельзя.
- В этапе `"choose": true` все узлы `also`.
- У каждой темы есть описание или внутренняя ссылка; не менее 65% тем имеют материалы.

### 9.2 Кейсы

Не менее 3 вариантов на вопрос, ровно один верный, пояснение у каждого варианта, тема у вопроса. Идентификаторы вопросов и вариантов уникальны в кейсе.

## 11. Границы

### 11.1 Не входит в MVP

| Элемент | Причина |
|---------|---------|
| Реальная аутентификация, регистрация, восстановление пароля, OAuth VK/Yandex | Нужна база пользователей и внешние интеграции; вход демонстрационный |
| Хранение данных кабинетов в БД | Кабинеты показывают условные данные |
| Чат, видеозвонки, календарь, уведомления | Вне ядра продукта |
| Админ-панель заявок | Вне MVP |
| REST API | `docs/docs.json` описывает будущий контракт, не реализован |
| Telegram-бот, мобильное приложение | Отложены |

### 11.2 Отложено

Статусы `reviewed`/`closed`, история прохождений кейсов, редактирование профиля ментора, поиск по roadmaps, rate-limiting.
